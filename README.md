# Project 1: Data Cleaning with Python

## Project Overview

This is the first project completed as part of the **DecodeLabs Data Analytics Internship**. The project focuses on cleaning and preparing a sales dataset using Python and Pandas. The goal is to improve data quality by handling missing values, validating records, standardizing data formats, and preparing the dataset for further analysis and visualization.

---

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- CSV Dataset

---

## Dataset

The dataset contains **1,200 sales records** with **14 columns**, including:

- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

---

## Tasks Performed

- Imported the dataset using Pandas.
- Explored the dataset structure and dimensions.
- Displayed dataset information and descriptive statistics.
- Checked the data types of all columns.
- Identified missing values.
- Filled missing values in the **CouponCode** column with **"No Coupon"**.
- Checked for duplicate records.
- Converted the **Date** column to the datetime format.
- Removed leading and trailing spaces from text columns.
- Verified that **TotalPrice** matched **Quantity × UnitPrice**.
- Checked for invalid numerical values.
- Exported the cleaned dataset as a new CSV file.

---

## Results

- Successfully cleaned the dataset.
- Handled all missing values appropriately.
- Standardized date and text formatting.
- Verified the accuracy of price calculations.
- Confirmed that no duplicate records existed.
- Prepared the dataset for Exploratory Data Analysis (EDA) and data visualization.
